About Me

GitHub | LinkedIn

Hey! I'm Jack Davey, a game design student based in Berkshire, UK, currently in my final year of college with a focus on programming.

I like building small tools and game mechanics when I've got free time. One of my main projects is Don't Drop It, a physics based delivery game where I built the package damage system and the delivery matching logic. I've also messed around with a few personal builds outside college, like a dictation tool, and I'm currently working on a DIY walking robot trained with reinforcement learning.

Outside of code, I run competitively with my local running club. Feel free to get in touch if you want to chat.
